# 项目术语表

**版本**: 1.2.0 | **创建日期**: 2026-01-08 | **最后更新**: 2026-01-08

> 本文档记录项目中使用的专有术语和概念定义，确保团队对概念理解一致。

## 使用说明

1. 按字母顺序或拼音顺序排列术语
2. 每个术语包含：中文名、英文名（如有）、定义、使用示例
3. 新增术语时请更新"最后更新"日期

## 术语列表

### Speckit 相关

| 术语 | 英文 | 定义 | 使用示例 |
|-----|------|-----|---------|
| 宪法 | Constitution | 项目的最高准则文档，定义核心原则和治理规则 | "所有代码变更必须符合宪法要求" |
| 规格说明 | Specification (Spec) | 功能需求的详细描述文档，包含用户故事和验收标准 | "请先完成规格说明的编写" |

### 开发流程

| 术语 | 英文 | 定义 | 使用示例 |
|-----|------|-----|---------|
| TDD | Test-Driven Development | 测试驱动开发，先写测试再写实现代码 | "我们采用TDD方式开发此功能" |
| YAGNI | You Aren't Gonna Need It | 简约设计原则，只实现当前需求 | "根据YAGNI原则，暂不添加该功能" |
| 用户故事 | User Story | 从用户视角描述的功能需求 | "这个用户故事的优先级是P1" |
| 验收标准 | Acceptance Criteria | 功能是否完成的判断条件 | "请检查是否满足所有验收标准" |
| PR | Pull Request | 代码合并请求 | "PR已创建，等待评审" |

### 航运业务领域

| 术语 | 英文 | 定义 | 使用示例 |
|-----|------|-----|---------|
| 港口 | Port | 船舶停靠、货物装卸的水陆交通枢纽设施 | "上海港是全球最繁忙的集装箱港口之一" |
| 港口代码 | Port Code | 港口的唯一标识符，遵循 UN/LOCODE 标准格式（2字母国家代码+3字母位置代码） | "上海港的港口代码是 CNSHA" |
| UN/LOCODE | United Nations Code for Trade and Transport Locations | 联合国贸易和运输位置代码，用于识别全球贸易和运输中的地点 | "我们使用 UN/LOCODE 作为港口标识标准" |
| 时区 | Timezone | 地球上使用同一标准时间的区域，通常以 UTC 偏移量或 IANA 时区名称表示 | "上海港位于 UTC+8 时区" |
| 精确查询 | Exact Search | 按港口代码完全匹配的查询模式，输入5位纯字母时自动触发 | "输入 CNSHA 执行精确查询" |
| 模糊查询 | Fuzzy Search | 按港口名称部分匹配的查询模式，支持中英文关键词 | "输入'上海'执行模糊查询" |
